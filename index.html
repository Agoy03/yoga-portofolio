Sistem Analisis Sentimen dan Text Mining Berbasis Web

Tugas akhir S1 Teknik Informatika, 2026

Aplikasi web yang mengolah data teks lalu menentukan sentimennya. Teks dibersihkan, dibobot dengan TF-IDF, dan diklasifikasikan dengan tiga algoritma: Naive Bayes, Support Vector Machine (SVM), dan Logistic Regression.

Pilih tahap di atas untuk melihat penjelasannya. Penjelasan bersifat umum untuk tiap tahap.

Naive Bayes
Menghitung peluang sebuah teks masuk ke suatu kelas dari kemunculan kata-katanya. Sederhana dan cepat untuk data teks.
Support Vector Machine
Mencari batas pemisah terbaik antar kelas sentimen berdasarkan fitur yang sudah dibobot.
Logistic Regression
Memperkirakan peluang sebuah teks termasuk ke suatu kelas sentimen.
